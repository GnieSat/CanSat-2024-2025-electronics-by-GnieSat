# CanSat 2024/2025 electronics by GnieSat
CanSat electronic schematics and PCB files from the 2024/2025 competition by ESA in Poland. Made by GnieSat.

Included: main PCB, power supply PCB, magnetometer PCB.

Open using KiCAD.

Known issues:
1. Main PCB:
  a. DBG_UART has swapped pins. Fix: enable pin swapping in the STM32.
